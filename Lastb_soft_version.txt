角色定位不同：专业工具 vs 一键型助手

核心技术原理不同

EasyRC：本质是PE内核重装。软件内置精简版WinPE环境，类似U盘PE的本地化变体。下载PE配置环境后重启进入，再调用安装程序完成部署，流程更接近传统PE

Notepad++ 在向日葵远程桌面中显示空白主要是由于渲染引擎冲突导致，具体来说：
DirectWrite 渲染问题：Notepad++ 使用的 DirectWrite 文本渲染技术在远程连接环境下可能无法正确显示内容
无显示器 / 笔记本合盖：当远程主机未连接显示器或笔记本电脑合上盖子时，显卡会进入低负载模式，导致依赖 GPU 加速的应用 (如 Notepad++) 显示异常
分辨率 / 缩放不匹配：远程与本地设备的显示配置差异可能导致 UI 渲染错误
图形界面兼容性：向日葵在捕获和传输某些应用程序界面时可能存在兼容性问题
解决方案
1. 禁用 Notepad++ 的 DirectWrite（推荐）
在远程主机上打开 Notepad++（即使界面空白，可通过点击标题栏区域操作）
按Alt+P打开 "设置→首选项"
切换到 "常用 (MISC)" 选项卡
找到 "Use DirectWrite" 选项，取消勾选
点击 "确定" 并重启 Notepad++

### 功能
- **统一管理**：添加、编辑、删除脚本；支持多种脚本类型：
  - **批处理**：`.bat`、`.cmd`
  - **Python**：`.py`
  - **Node.js**：`.js`、`.mjs`、`.cjs`、`.ts`、`.jsx`、`.tsx`
  - **PowerShell**：`.ps1`
  - **VBScript**：`.vbs`
  - **JScript**：`.js`、`.jse`（优先识别为 Node.js）
  - **WSF**：`.wsf`
  - **Shell**：`.sh`（Git Bash/WSL）
- **启动 / 停止 / 重启**：对选中项一键操作；停止时会结束进程树（含子进程）

- **点击访问**：工具栏「访问」或右键「访问 :端口」、弹窗内「:端口」按钮，在浏览器打开 `http://localhost:端口`
- **进程查看与资源监控**：选中运行中的项，点「端口/进程」可查看主进程及子进程的 PID、名称、路径、CPU%、内存 MB（需 `psutil`）

Python 版本选择：稳定性与组件支持分析
从你提供的 Python 官方下载页面信息来看，结合稳定性和组件兼容性两大核心需求，我为你梳理出最适合的版本选择方案：
1. 首选推荐：Python 3.12.x（以 3.12.10 为例）
稳定性：3.12 系列是目前官方维护的稳定版，bug 修复和安全更新持续跟进，且经过了大量生产环境验证。
组件支持：
主流第三方库（如 pandas、numpy、Django、Flask、requests 等）均已完全适配 3.12。
兼容绝大多数企业级组件和工具链（如 PyTorch 2.2+、TensorFlow 2.15+、Poetry、Pipenv 等）。
适配性：仅不支持 Windows 7 及更早系统，适合现代 Windows 10/11、macOS、Linux 环境。
https://www.423down.com/14557.html
2. 兼容优先：Python 3.11.x（以 3.11.9 为例）
稳定性：3.11 是 LTS 级别的稳定版本，官方长期维护，bug 少、运行稳定。
组件支持：
对老旧库 / 组件的兼容性最佳（比如部分未及时更新的企业内部组件、小众库）。
是目前工业界使用最广泛的版本之一，几乎无组件兼容问题。
适配性：同样不支持 Windows 7，但适配所有主流开发 / 生产环境。
3. 最新稳定版：Python 3.14.3（谨慎选择）
稳定性：作为最新正式版，功能最新，但部分边缘场景的 bug 可能尚未完全修复。
组件支持：
主流库已适配，但少数小众 / 老旧组件可能存在兼容性问题。
适合尝新或对新特性有明确需求的场景，不建议生产环境直接使用。
4. 不推荐版本
Python 2.7.x：已完全停止维护，无安全更新，绝大多数新组件不再支持。
Python 3.9 及更早：虽稳定但逐渐被淘汰，部分新库（如新版 FastAPI）已不再适配。
预发布版（3.15.0a6 等）：仅用于测试，存在大量未修复的 bug，绝对禁止生产环境使用。
总结
生产环境首选：Python 3.11.x（兼容性天花板）或 3.12.x（平衡新特性与稳定性）。
组件兼容核心原则：优先选择发布超过 6 个月的稳定版，避开最新大版本（如 3.14）和预发布版。
特殊场景：若需兼容 Windows 7，需降级到 Python 3.8.10（最后支持 Win7 的版本），但需承担安全风险

密码破解工具
真能吃显卡的压缩包密码恢复工具，主要分两条路：免费开源的命令行派（hashcat 是标杆） 和 Windows GUI 商业派（Accent/PassFab/Passware 这类）。ARCHPR 零售版之所以被嫌弃，就是因为它 GPU 调用浅，下面这几个才是真·GPU 加速。
🥇 Hashcat —— GPU 密码恢复的标杆
开源免费，支持 300+ 算法，RAR5（-m 13000）/ ZIP AES（-m 13600）/ RAR3（-m 12500）全齐，CUDA + OpenCL 双引擎，NVIDIA/AMD 都能挂，速度比 ARCHPR 零售版高一到两个数量级。
典型流程（Windows 举例）：
# 1. 提哈希（用 John the Ripper 附带的 rar2john/zip2john）
rar2john secret.rar > rar_hash.txt
zip2john "文件.zip" > zip_hash.txt
# 2. GPU 字典攻击
hashcat.exe -m 13000 -a 0 rar_hash.txt rockyou.txt -O -w 3
# 3. 掩码攻击（记得后四位是数字）
hashcat.exe -m 13600 -a 3 zip_hash.txt ?u?l?l?l?d?d?d?d
关键参数：
• -m 13000 = RAR5，-m 13600 = ZIP AES（PKZIP Compressed 也可能是 17200/17225，看 zip2john 输出的前缀定）
• -a 0 字典 / -a 3 掩码 / -a 6 字典+掩码
• -w 3/4 拉满 GPU 工作负载（4 会影响前台流畅度）
• -O 内核优化，RAR5/ZIP-AES 必加，否则速度打骨折
• hashcat -I 先验 GPU 是否被识别，看不到就是驱动/CUDA 没装对
💡 速度量级参考：RTX 4090 跑 RAR5（PBKDF2-HMAC-SHA256 × 262144 轮）大约 10 万 H/s 级别，8 位复杂密码纯暴力仍要按月算，但字典+规则能压到分钟级。这活 ARCHPR 零售版 CPU 跑是几千 H/s，差几十倍。
🥈 John the Ripper（Jumbo 版）—— 半 GPU
Hashcat 的"老对手"，RAR5/ZIP-AES 的 GPU 支持不如 hashcat 深，但好处是自带 rar2john / zip2john 提哈希，很多人是 JtR 提 hash + hashcat 跑 GPU 的组合拳。如果你已经装了 Jumbo，懒得另下 hashcat 也可以直接 --fork 多 GPU，但速度确实差一截。

下面给你两条在 iPhone 上跑谷歌 Gemma 的实操路线，路线 A 最省事（官方 App），路线 B 更灵活（自选 GGUF）。都完全离线、不联网、不上传数据。
路线 A：Google AI Edge Gallery（官方、小白首选）
适用：iOS 17+，iPhone 12 及更新（E2B 基本都能跑，E4B 建议 15 Pro / 16 系列 8GB RAM）
1. 下 App
   App Store 搜 Google AI Edge Gallery，开发者认准 Google LLC，国区没有就切美区 ID。
2. 选模型
   打开 App → AI Chat 或 Agent Skills → 模型列表里会有：
   • Gemma 4 E2B IT（约 2.5GB）——首推，速度快、6GB RAM 机器也能跑
   - Gemma 4 E4B IT（约 3.6GB）——质量更好，吃内存，旗舰机再选
3. 下载权重
   点 Download，连 Wi-Fi，别切后台。E2B 大概 2–4 分钟下完，App 会在本机按芯片（A16/A17/A18）做一次编译优化。
4. 开聊 + 验离线
   下完直接进对话，首次加载 10–30 秒。然后开飞行模式再问一句，能答出来就是纯本地跑通了。
5. 顺手可玩的功能
   • Thinking Mode（看链式推理）
   - Ask Image（拍图/选图让模型看）
   • Audio Scribe（本机语音转写/翻译）
   • Prompt Lab（调温度、top-p 等参数）
坑点：iPhone 12 有用户反馈下不动 E4B，老机型一律先 E2B；长时间生成会发热降速，正常现象。
路线 B：PocketPal AI（开源、可换任意 GGUF）
适用：想自己挑量化档位、试 Gemma 3 / 4 以外模型（Qwen、Llama 等）的人。
1. App Store 搜 PocketPal AI（开源，by LLM Ventures / 社区版），装好打开。
2. 底部 Models → + / Add Model → Download from Hugging Face。
3. 搜 Gemma 的 GGUF 仓库，常用：
   • bartowski/google_gemma-4-E2B-it-GGUF → 选 Q4_K_M.gguf（~1.3–2.5GB，均衡档）
   - 老机型（iPhone 13 及以前 4–6GB RAM）→ 找 gemma-3-1b-it-Q4_K_M.gguf（~700MB）
4. 点 Download → 下完点 Load → 进 Chat 就能用，同样断网可聊。
5. 进阶：设置里把 Max Context 调到 2560 左右（Gemma 4 支持 3072，但 A15 别拉满防 OOM），Temperature 做严肃任务降到 0.3 以下。
PocketPal 内置精选列表可能还没收 Gemma 4，需要手动填 HF 仓库名；如果搜不到就确认拼写或换网络。
机型 × 模型速查
机型 RAM 推荐模型
iPhone 16 / 15 Pro 系列 8GB E4B Q4_K_M 舒服，E2B 更省电
iPhone 14 Pro / 14 6GB E2B 稳，E4B 偶尔吃紧
iPhone 13 及更早 4–6GB 只跑 E2B，或退到 Gemma 3 1B Q4
iPhone 12 及以下 ≤4GB 不建议硬跑，容易 OOM
存储留 4–6GB 余量，模型删 App 就一起清掉。
一个判断小技巧
装完别信“它说离线”，真验一次：飞行模式 + 问“1+1 等于几”，答得快且对，就是本机推理；卡住转圈才是偷偷走网。

安卓上跑谷歌 Gemma 端侧模型，思路和 iPhone 一样分官方 App 派和第三方加载派，但生态比 iOS 还乱一点，给你捋清楚：
路线 A：Google AI Edge Gallery（安卓版，最省事）
谷歌把同一个项目也出了 Android 版，目前是早期预览 APK，不在国内商店上架。
• 去 GitHub 搜 google-ai-edge/gallery → Releases 里下 ai-edge-gallery.apk（ARM64）
- 手机允许「未知来源安装」装上
• 打开 → AI Chat → 模型列表里选 Gemma 4 E2B IT（首推）或 E4B IT
• 点下载权重（E2B 约 2.5GB，E4B 约 3.6GB），走 Wi-Fi
- 下完断网问一句，能答就是纯本地
• 支持 Ask Image、Audio Scribe、Prompt Lab，和 iOS 版功能对齐
机型门槛：骁龙 8 Gen2 / 天玑 9300 / 麒麟 9000S 及以上体验好；骁龙 7+ Gen3、8 Gen1 能跑 E2B 但稍慢；4GB RAM 老机别碰 E4B。
路线 B：第三方 App 加载 GGUF（最灵活）
安卓上这类工具比 iOS 多：
• PocketPal AI：有安卓版（GitHub Releases 或 F-Droid），操作和 iOS 一样，HF 搜 bartowski/google_gemma-4-E2B-it-GGUF 下 Q4_K_M.gguf
- LM Studio（安卓内测）：官方出了 Android 内测包，界面和桌面版一致，直接搜 Gemma 4 下载
• Ollama 安卓？ 官方没出，但有 Termux + ollama 野路子（需 root 或高级终端权限，新手不推荐）
- MLC Chat（APK）：Apache TVM 后端，对高通 NPU 利用更好，但模型库更新慢，Gemma 4 可能要等社区配型
安卓特有坑（iPhone 没有的）
1. NNAPI / GPU 委托：AI Edge Gallery 默认走 CPU 也行，但想在骁龙上提速要在设置里开 GPU delegate（部分驱动会崩，崩了退回 CPU）
2. 厂商后台杀进程：小米/OPPO/vivo 要把 App 加内存锁定/自启动白名单，不然生成到一半被回收，报的不是“文件占用”而是直接闪退
3. 存储空间：安卓机容易把权重下到内部存储，记得进 App 设置改默认模型目录到 SD 卡（如果支持），E4B 留 5GB 余量
4. SELinux：极少见，但某些国产 ROM 会拦本机推理引擎 mmap，报类似“user-mapped section”的底层错——这时候反而和你在 Windows 上看到的 Sublime 报错是同一类文件系统锁逻辑（mmap 区域被占）
安卓 vs iPhone 速选
• 不想折腾 → AI Edge Gallery APK + Gemma 4 E2B
• 想换 Qwen/Llama 一起玩 → PocketPal AI
- 骁龙 8 Gen3 且会调 → MLC Chat 开 NPU 推理最快
