手机 · Android

要装 OlliteRT

要装什么

  1. 打开 OlliteRT Releases，下载最新 APK（仓库未上架 Google Play / F-Droid，官方只发 GitHub 包）。
  2. 手机允许「未知来源」安装后装上。源码与说明：NightMean/OlliteRT（Apache 2.0）。
  3. 系统要求（README）：Android 12+ · arm64-v8a · RAM ≥ 6 GB（多模态建议 8 GB+）。

装完怎么跑起来

  1. 打开 App → 下载模型。多数机子先下 Gemma 4 E2B（约 2.4 GB，表列 8 GB RAM）。
  2. 在模型卡片点 Start Server。
  3. 看 Status 页的地址，例如 http://PHONE_IP:8000/v1，用 Open WebUI / curl / 任意 OpenAI 兼容客户端连上。

只认 .litertlm，不支持 GGUF。同时只加载一个模型，请求串行排队。推理走 Google LiteRT-LM。

来源：OlliteRT README · MODELS.md（2026-09-23）。

能装的模型（含 Qwen）

  • Qwen：能装，但只有小档。内置表列 Qwen 2.5 1.5B（约 1.5 GB · 6 GB RAM · 4K · 纯文本）——偏闲聊 / 演示，不要用来干活。没核实到内置更大的 Qwen3 / 27B。
  • 能干活（有上限）：Gemma 4 E2B（约 2.4 GB · 8 GB RAM）默认起步；内存够再试 E4B。看图/听音频用 Gemma 3n。
  • 同类闲聊档：Gemma 3 1B、DeepSeek-R1 1.5B（同表）。

来源：OlliteRT README「Available Models」表（NightMean/OlliteRT）。

手机 · iOS

要装 App

没有 OlliteRT 的 iOS 版。下面两条是 App Store 上已核实、可本机跑模型的路径（不是云端聊天壳）。

路径 A · Google AI Edge Gallery（官方 LiteRT 画廊）

  1. App Store 搜或打开 Google AI Edge Gallery 安装。
  2. 系统：官方 README 写 iOS 17+（Android 另有 12+；本段只谈 iPhone）。
  3. 装完：在 App 内从列表下载模型（含 Gemma 4 族等），即可离线对话、看图、转录等实验功能；推理在本机。

源码：google-ai-edge/gallery。这是「手机上试模型」的官方画廊，不是把手机变成局域网 OpenAI 服务（那是 Android 上 OlliteRT 的事）。自定义 .litertlm 导入文档目前偏 Android（adb），iPhone 侧以 App 内列表为准。

路径 B · Locally AI by LM Studio（MLX 本机）

  1. App Store：Locally AI by LM Studio；官网 locallyai.app。
  2. 系统：商店页写 iOS / iPadOS 18.1+。
  3. 装完：选模型下载（Llama / Gemma / Qwen / DeepSeek 等，以 App 内列表为准）→ 离线聊天。走 Apple MLX，数据不出机。

可选：同机还可连电脑上的 LM Studio（LM Link）跑更大模型——那是「手机遥控电脑」，不算纯端侧。

能装的模型（含 Qwen）

  • Gallery · Qwen：小档可跑，主推仍是 Gemma。README 主推 Gemma 4。LiteRT-LM 官方支持表另列 Qwen2.5-0.5B / 1.5B、Qwen3-0.6B（约 0.5–1.6 GB 量级，偏闲聊）；litert-community 有对应权重。Gallery 1.0.16+ 可从 Hugging Face 导入 .litertlm——iOS 默认列表里有没有 Qwen 以 App 内为准，没在商店页写死「一键含 Qwen」。
  • Locally AI · Qwen：能装。官网 FAQ 写明支持 Qwen 2.5、Qwen 3（另有 Gemma、DeepSeek R1、Llama 等）；具体标签与体积以 App 内列表为准。手机内存有限，别硬上桌面 27B。
  • 能干活（有上限）：Gallery 的 Gemma 4 档、Locally 里中等开源档——短文 / 看图 / 草稿；别当云端旗舰。
  • 偏闲聊：Qwen 0.5B～1.5B、极小演示档。

来源：LiteRT-LM Overview · gallery README · locallyai.app FAQ。

Mac（Apple Silicon 笔记本）

本机可跑

统一内存决定能塞多大模型——以你这台为准（「关于本机」）。下面三条都是官方可下的本机方案，任选其一即可起步；不必全装。

方案 1 · Ollama（最省事）

  1. 打开 ollama.com/download/mac，下 macOS 安装包（或文档写的 curl … | sh）。
  2. 要求（官方 docs）：macOS 14 Sonoma+；Apple M 系列有 CPU+GPU，Intel Mac 仅 CPU。
  3. 装法：挂载 ollama.dmg → 拖进「应用程序」→ 首次启动可把 CLI 链到 /usr/local/bin。
  4. 跑起来：终端执行 ollama run gemma4（或库里其它标签，以 ollama.com/library 为准）。本地 API 默认本机端口，可接 Open WebUI 等。

来源：docs.ollama.com/macos · Quickstart。

方案 2 · LM Studio（图形界面）

  1. 打开 lmstudio.ai/download，选 macOS。
  2. 要求（官方）：Apple Silicon（M1–M4） · macOS 14.0+ · 建议 16GB+ 内存（8GB 只能硬扛小模型）。Intel Mac 当前不支持。
  3. 装完：App 内搜模型 → 下 GGUF / 官方列表 → 聊天；也能开本机 OpenAI 兼容服务（端口以 App 设置为准）。Apple Silicon 上另支持 MLX 引擎（官方文档说明）。

来源：LM Studio System Requirements。

方案 3 · mlx-lm（命令行 / 开发）

  1. pip install mlx-lm（或 conda-forge）。仓库：ml-explore/mlx-lm。
  2. README 注明：大模型加速相关能力需要 macOS 15+；须用 Apple Silicon 上的原生 ARM Python。
  3. 跑起来：按 README 用 mlx_lm.generate 等命令拉 HF 上的 MLX 权重（如 mlx-community 预转换档）。

来源：mlx-lm GitHub README / PyPI。

可选 · 从源码编 llama.cpp（Metal）

适合要 GGUF 命令行的人：按 llama.cpp build.md，macOS 上 Metal 默认开启；cmake -B build && cmake --build build --config Release。日常聊天优先 Ollama / LM Studio 更省事。

能装的模型（含 Qwen）

  • Qwen：四个运行时都能装（格式不同）。
    • Ollama：库有 qwen2.5（0.5B～72B）、qwen3（0.6B～235B）、qwen3.8（含 qwen3.8:27b，约 18GB）。例：ollama run qwen3:8b 或内存够时 ollama run qwen3.8:27b。
    • LM Studio：App 内搜「Qwen」或走 HF GGUF/MLX；Qwen 官方文档写了 LM Studio 装法（Qwen · LM Studio）。
    • mlx-lm：Qwen 文档确认支持；可用 Qwen/…-MLX 或 mlx-community 预转换档（Qwen · MLX LM）。
    • llama.cpp：跑社区 GGUF（含 Qwen 族）——命令行自备权重，日常优先前三个。
  • 能干活：统一内存够时，本站口径的 Qwen3.8-27B、Gemma 4 等——写码、长文档、本机 Agent 草稿。分档见 本地模型。
  • 偏闲聊：qwen3:0.6b / qwen2.5:0.5b～1.5b、8GB 硬扛小档——只适合演示。
  • 别混：云端 Qwen API / ChatGPT 网页不是本机安装。

Mac mini

同 Apple Silicon · 常开盒子

装什么、怎么跑：与上面 Mac 笔记本相同（Ollama / LM Studio / mlx-lm）。芯片仍是 Apple Silicon 统一内存，软件不换。

和笔记本差在哪

  • 形态：无内置屏，接显示器或当无头局域网推理盒；适合 24h 挂着给家里其它设备打 API。
  • 内存：以你这台的统一内存为准。Apple 对 Mac mini (2024) 官方规格写：M4 起步 16GB，可配 24GB / 32GB；M4 Pro 起步 24GB，可配更高（见 Apple Support · Tech Specs）。别把「别人那台 32GB」当成你的门槛。
  • 选型：内存档位决定能塞多大——装完后仍回 本地模型 看 27B 类能干活档，本页不重复街货价表。

装完怎么当小服务器

Ollama / LM Studio 开本机服务后，同一局域网用 Open WebUI、IDE、脚本打 API 即可。防火墙与是否绑定 0.0.0.0 以各软件设置为准——别把机器裸奔到公网。

能装的模型（含 Qwen）

与上面 Mac 笔记本同一套库：Ollama / LM Studio / mlx-lm / llama.cpp 都能下 Qwen（含 qwen3.8:27b 等）。差别只在统一内存够不够——以你这台为准，选型长文回 本地模型。

Windows 小主机 / NUC · Linux 盒子

去本地模型页选型

这一类和「台式机 / 独显本」是同一套本机栈。端侧页只写怎么装运行时；显存分档、街货价、27B 选型全部在 本地模型。

要装什么（官方核实）

  • Ollama：Windows 打开 ollama.com/download，要求 Windows 10+（官方页）；Linux 用官网安装脚本。装完 ollama run …。
  • LM Studio：lmstudio.ai/download。Windows：x64（需 AVX2）或 ARM；建议 ≥16GB RAM、独显建议 ≥4GB VRAM。Linux：AppImage，官方写 Ubuntu 20.04+（新于 22 的版本标注「未充分测试」）。

来源：Ollama 下载页 · LM Studio System Requirements。

能装的模型（含 Qwen）

  • Qwen：能装。Ollama 库有 qwen2.5 / qwen3 / qwen3.8（含 27B）；LM Studio App 内搜 Qwen 或下 HF GGUF。来源同 Mac 段链接。
  • 能干活：按显存选 Qwen3.8-27B / Gemma 4 等——分档、街货价、去 本地模型。
  • 偏闲聊：小参数演示档。不要把云端旗舰写成「NUC 本机已跑通」。

常见问题
OlliteRT 能直接跑 Ollama 的 GGUF 吗？▼
不能。README 写明只支持 .litertlm。GGUF 请用电脑上的 Ollama / llama.cpp，见本地模型页。
工具调用可靠吗？▼
OlliteRT 标明 experimental，且依赖模型本身（Gemma 4 较好）。不要默认当成生产 Agent 的硬依赖。
和 Google AI Edge Gallery 什么关系？▼
Credits 写明基于 Google AI Edge Gallery，再做成可对外提供 OpenAI 兼容服务的服务器形态。
这些端侧能装 Qwen 吗？▼
能，但档位差很多。Android OlliteRT 内置只有 Qwen 2.5 1.5B（闲聊）。iPhone：Locally AI 明确写 Qwen 2.5/3；Gallery 侧 LiteRT 有小档 Qwen，主推仍是 Gemma 4。Mac / Mac mini / Windows·Linux：Ollama、LM Studio、mlx-lm 都能下 Qwen，内存够可到 qwen3.8:27b 干活档——见各终端「能装的模型」段与 本地模型。

一句话怎么用

Android → 装 OlliteRT APK + Gemma 4 E2B
iPhone → Gallery 或 Locally AI
Mac / mini → Ollama 或 LM Studio
选多大模型 → 本地模型
