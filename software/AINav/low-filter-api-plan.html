接到现有工具
OpenAI SDK · 只换入口

下面只示范兼容方式：换 base URL、密钥和模型 ID。不包含绕过安全策略的提示词。

from openai import OpenAI import os client = OpenAI( api_key=os.environ["VENICE_API_KEY"], base_url="https://api.venice.ai/api/v1", ) r = client.chat.completions.create( model="gemma-4-uncensored", messages=[{"role": "user", "content": "Summarize this security report."}], )

Cursor / Cline 等：选 OpenAI 兼容提供商，Base URL 填上列地址，模型填文档里的 ID。NinjaChat 把 base URL 换成 https://www.ninjachat.ai/api/v1、模型换成 uncensored-ai 即可。

Strix 自动化审计 · 模型怎么选

Strix（Apache 2.0）是开源 AI 渗透 Agent：多 Agent 侦察 / 利用 / 验证，要求漏洞带可复现 PoC。底层走 LiteLLM，STRIX_LLM 用 provider/model 格式。 官方推荐档：glm-5.3 / gpt-5.4 / claude-sonnet-4-6 / gemini-3-pro（见 LLM Providers）。 下表按用途分档——DeepSeek Flash 只做便宜快扫，不是最强深扫。

用途Strix 里写（STRIX_LLM）渠道定位
日常快扫 deepseek/deepseek-flash DeepSeek 官网 对应 V4.1-Flash；便宜、快。复杂攻击链弱。别当深扫主力。

红队 / 安全评测（样本不被过度拒答污染）
Venice 低过滤开源 ID，或 NinjaChat uncensored-ai
评测拒答率、有害内容分类、策略覆盖时，过度拒答会污染样本。用低过滤开源权重做对照，不等于取消你自己的安全层——对外服务仍应自建过滤。这和下面 Strix「要长程 Agent 智商」不是同一档选型。
Strix · CI / PR 快扫
deepseek/deepseek-flash 或 openrouter/z-ai/glm-5.3-flash；默认稳妥用 glm-5.3
要短、要省。Flash 复杂链弱，适合 diff / quick 门禁。第三方案例口径：Quick 约数分钟到十几分钟、费用常见个位数美元量级——以你自己账单为准，本站不写死刊例。
Strix · 全面深扫 / 要可交付报告
先 openrouter/z-ai/glm-5.3；DeepSeek 生态注意 deepseek-v4-pro 过渡期可能仍落到 Flash——要报告质量用 gpt-5.4 / claude-sonnet-4-6（或 Vertex gemini-3-pro-preview）
不要用 Flash 顶深扫。文章与独立横评都指向：弱模型会漏报或早停；编排层很重要，但模型智商仍是拉开差距的关键。贵模型单次可能很高（如 Sonnet 经中转限额后的极端账单），先小目标试跑。
减少过度拒答的日常文本 / 代码
Venice gemma-4-uncensored 或 venice-uncensored-1-2
单价低、按 token 可预期。长上下文或更强推理再看 qwen-3-6-plus / Hermes 3 405B。官方 Claude、GPT 即便从 Venice 走，也不是本页意义上的低过滤档。
本机已有 GPU / 数据不能出域
优先看 本地模型横评；Strix 可接 Ollama / 兼容本地入口
云 API 省运维；隐私优先再自托管。Strix 官方也写：关键评估仍建议云端强模型，小参数本机 Agent 往往跟不动多步工具循环。
常见问题
和 OpenRouter、Together 有什么区别？▼
主流推理云也会上架部分 abliterated 开源权重，但产品定位是全模型路由，不是本页这种对照。日常多模型、旗舰编码请走百科「AI 模型 API」和 模型选型。Strix 默认的 openrouter/z-ai/glm-5.3 走的是 OpenRouter 上的智谱线，属于「Agent 智商」选型，不是「低过滤权重」选型。
DeepSeek Flash 能不能当 Strix 深扫主力？▼
不能。Flash（现为 V4.1-Flash，API deepseek-flash）只适合便宜快扫。深扫默认用 glm-5.3；DeepSeek 的 deepseek-v4-pro 在 V4.1-Pro 上线前可能仍转发 Flash。报告质量优先再上 GPT-5.4 / Claude Sonnet 4.6 / Gemini 3 Pro。
Pro 套餐无限聊，API 是不是也无限？▼
不是。Venice 官方 FAQ：Web/App 的无限文本与每日图像上限，不含 API。API 按 token 扣 credits。Pro 每月 100 credits 大约只够试接口；认真跑评测或 Agent 请按量充值，或改用 Pro+ / Max 的月度 credits。
按次 $0.003 一定比按 token 便宜吗？▼
NinjaChat 的 uncensored-ai 是每次请求固定价。一次生成很长代码往往更划算；若你打成千上万次超短请求，按 token 的小模型可能更便宜。先用小额余额跑自己的真实流量再决定。
低过滤是不是「零审查」？▼
不是。Abliterated 权重通常只是削弱了训练里的拒答方向，服务商仍有条款、支付风控和地区政策。Strix 等自动化审计只测你有权测的目标。本站不用「零审查」当标题，也不保证任何请求都会被执行。违法用途不要做。
