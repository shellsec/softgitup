本地 vs API：什么时候买卡才划算
路径单价适合不适合
Ollama / llama.cpp 本地 权重 ¥0 + 电费 隐私、离线、每天大量对话/编码 偶发试用（卡还没回本）
Qwen3.8-27B API $0.33 / $2.40 每百万 token 不想养卡、要 262K 满窗 数据不能出机房
云端旗舰 API 见 模型选型 要 Qwen 3.8 Max / GLM-5.3 / Claude 那档智商 把「开源第一」误当成单卡能跑

粗算：二手 3090 ¥4,000 摊 24 个月 ≈ ¥167/月，再加约 ¥50 电费（350W、每天 8 小时、¥0.6/度）。Qwen3.8-27B API 按混合约 $1/百万 token 计，月用量不到约 300 万 token 时买卡往往更贵；日用编码 Agent、或必须不出网，才轮到本地。

场景怎么配
日常本地助手（中文 + 偶尔看图）
候选：Qwen3.8-27B、Gemma 4 12B/31B、Qwen3.6-27B
24GB → Qwen3.8-27B Q4；8–12GB → Gemma 4 12B
  • 3.8-27B 带视觉 projector，Ollama 默认标签已接好
  • 把 reasoning 从默认 xhigh 降到 medium，否则首 token 会想很久
本地 Coding Agent（Aider / Continue / Cline）
候选：Qwen3.8-27B、Qwen3.6-27B、Mellum2（8GB）、Kimi K2.6（机房）
本机 24GB → qwen3.8:27b 或 qwen3.6；连 Aider 的 OpenAI 兼容口
  • BenchLM 单卡编码仍写 Qwen3.6-27B（SWE-bench 77.2）；3.8-27B 更新但目录分尚未跟上
  • K2.6 编码更强（80.2）但要 8×H100，和个人 Ollama 不是同一场
长文档 / 隐私离线
候选：Qwen3.8-27B 32K–64K、Gemma 4 31B 256K 纸面
24GB 先锁 32K；96G 工作站可本机满 262K；要百万字请改走 DeepSeek-V4-Pro API
  • 混合注意力让 32K 很便宜，满 262K 会把 24GB 顶满；RTX PRO 6000 96G 装 27B BF16 + 满窗仍有余量
  • 端侧手机/IoT 仍看 Gemma 4 E2B，不是桌面 GGUF

一句话速查

96GB 单卡工作站 → RTX PRO 6000（120B Q4）
