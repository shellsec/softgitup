### 功能
- **统一管理**：添加、编辑、删除脚本；支持多种脚本类型：
  - **批处理**：`.bat`、`.cmd`
  - **Python**：`.py`
  - **Node.js**：`.js`、`.mjs`、`.cjs`、`.ts`、`.jsx`、`.tsx`
  - **PowerShell**：`.ps1`
  - **VBScript**：`.vbs`
  - **JScript**：`.js`、`.jse`（优先识别为 Node.js）
  - **WSF**：`.wsf`
  - **Shell**：`.sh`（Git Bash/WSL）
- **启动 / 停止 / 重启**：对选中项一键操作；停止时会结束进程树（含子进程）
- **路径与工作目录**：每条记录可设置脚本路径和工作目录，配置保存到 `config.json`，下次打开自动加载

- **运行中接管**：列表中已有、但从外部（如 CMD、资源管理器）启动的脚本（含 .exe），会在刷新时按路径自动匹配并显示为「运行中」，无需再点「启动」；需 `psutil`
- **端口识别**：自动显示该进程树正在监听的端口（依赖 `psutil`，无则用 `netstat -ano` 降级）
- **页面标题**：表格「标题」列自动获取 Web 服务的页面标题（后台异步获取，不阻塞 UI）
- **点击访问**：工具栏「访问」或右键「访问 :端口」、弹窗内「:端口」按钮，在浏览器打开 `http://localhost:端口`
- **进程查看与资源监控**：选中运行中的项，点「端口/进程」可查看主进程及子进程的 PID、名称、路径、CPU%、内存 MB（需 `psutil`）
- **扫描运行中**：识别**系统当前正在运行**的脚本进程（从命令行解析脚本路径），可「加入管理器」或「全部加入」纳入管理，也可「结束选中」
- **全部启动 / 全部停止**：一键启动或停止列表中所有项
- **停止软件外所有批处理**：停止系统中所有正在运行的批处理脚本（包括列表中的和列表外的）
- **复制**：克隆选中项（名称加「(副本)」），可再编辑后用作变体
- **指定解释器**：
  - **Python**：可填 `py -3.11`、解释器路径等，留空即用当前 Python

- **崩溃自动重启（保活）**：编辑时勾选「崩溃后自动重启(保活)」，进程异常退出时每隔几秒自动重新启动（在编辑弹窗中设置，表格不显示）

按系统快速选：Windows 用 PowerToys（官方免费、零门槛），Mac 用 Karabiner-Elements（免费开源、功能强），追求极简可选专用小工具（如 Keyvol）。下面是分平台的具体方案与 SOP。
一、 Windows 平台（首选 PowerToys）
1. 微软官方 PowerToys（最推荐）
优势：官方免费、安全无风险、无需脚本、设置即用，还能管理其他快捷键冲突
一键音量映射方案：
功能  推荐映射键 对应系统功能
静音 / 取消静音 F10 Volume Mute
音量减小  F11 Volume Down
音量增大  F12 Volume Up
设置 SOP（3 步到位）：
安装：官网 https://github.com/microsoft/PowerToys 下载安装并启动
打开：PowerToys 设置 → 左侧菜单选择 Keyboard Manager → 开启右侧开关
映射：点击 Remap a shortcut → 按以下步骤配置（以 F10 静音为例）：
按 Type shortcut → 按下 F10 → 确定
按 Type shortcut → 点击下拉菜单选 Volume Mute → 确定
点击 OK 保存，立即生效
2. 备选方案（按需求选择）
AutoHotkey（适合需要 OSD 或进阶功能）
脚本示例（保存为.ahk文件运行）：
autohotkey
F10::Send {Volume_Mute}      ; F10静音
F11::Send {Volume_Down 4}    ; F11音量减4%
F12::Send {Volume_Up 4}      ; F12音量加4%
优势：可添加音量条显示（OSD），支持连续按快速调节
官网：https://www.autohotkey.com/
Keyvol（极简专用工具）
特点：双击运行即生效，默认 F10 静音、F11 减、F12 加，任务栏托盘隐藏，退出右键点 EXIT
适合：不想装大工具、临时使用的场景
二、 Mac 平台（首选 Karabiner-Elements）
Karabiner-Elements（免费开源，Mac 首选）
优势：Mac 平台最强大的按键映射工具，可区分不同键盘设备单独设置，兼容最新 macOS
一键音量设置 SOP：
安装：官网 https://karabiner-elements.pqrs.org/ 下载安装并授权
配置：打开 Karabiner-Elements → 切换到 Complex Modifications 标签
添加规则：
点击 Add rule → 搜索框输入 volume
找到 Change F10/F11/F12 to volume controls → 点击 Enable
立即生效，无需重启
备选：系统自带（基础版）
路径：系统设置 → 键盘 → 键盘快捷键 → 声音 → 可修改默认快捷键，但无法映射单键（只能改组合键）
三、 跨平台极简方案（适合临时 / 轻量使用）

五、 避坑与优化建议
冲突处理：先关闭其他可能占用 F10-F12 的软件（如某些编辑器、游戏）
