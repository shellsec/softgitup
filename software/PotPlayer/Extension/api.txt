string HostGetCookie()
	Get the cookies of this script's web account site as "name1=value1; name2=value2"
	The site is the first host of GetWebAccountDomain() (or the host of GetWebAccountUrl() if no domain is given)
	Cookies are the ones saved by the web account login window and the broadcast list browser

int HostCreateThread(__ThreadFunction@ callback, const ?&in param = null)
	Create a thread for background work and return its thread ID
	Protect resources shared between threads with Mutex
	callback : signature is 'void Function(any@ param)'. param is passed to it as any@
	example:
		void ThreadFunction(any@ param)
		{
			if (param != null)
			{
				string str;
				int num;

				if (param.retrieve(str)) HostMessageBox("ThreadFunction " + str);
				else if (param.retrieve(num)) HostMessageBox("ThreadFunction " + formatInt(num));
			}
		}
		void OnInitialize()
		{
			HostCreateThread(ThreadFunction, "test");
			HostCreateThread(ThreadFunction, 123);
		}

bool HostWaitThread(int threadID, int ms = 10)
	Wait up to ms milliseconds for the thread to finish
	A long wait may cause a script timeout.
	To wait for a long time, wait for short periods in a loop
	and call HostIncTimeOut in the loop to extend the timeout.
	Returns true if the thread finished, false on timeout

------------------------MediaPlayParse MetaData----------------------------------
string PlayitemParse(const string &in path, dictionary &MetaData, array<dictionary> &QualityList)
	Keys that PotPlayer reads from MetaData (all optional)

	vid             string : video id, unique and stable within the site
	                         Used as the key of "Remember playback position" (and remembered audio/subtitle track)
	                         together with the site domain of webUrl (or of the opened url), e.g. "bilibili.com|BV1xx"
	                         URLs are remembered only when vid is set, because the same video can be opened with
	                         different query strings. Give each part of a multi-part video its own vid
	webUrl          string : canonical web page url of the video
	title, author, content, date, fileExt, thumbnail, viewCount, likeCount, dislikeCount : string
	errorMessage    string : message shown when playback fails
	duration        int    : length in milliseconds
	seek            int    : start position in seconds. Used when no other start position is given
	                         (command line, playlist position, YouTube t=); it takes priority over the remembered position
	type3D          int    : 1 SBS half, 2 SBS full, 3 T&B half, 4 T&B full
	is360, is180    int    : 1 for 360 / 180 degree video (is180 also needs is360)
	chatUrl         string : page opened in the chat window
	chatScript      string : JavaScript injected into the chatUrl page (needs chatUrl)
	subtitle        array<dictionary> : name, langTranslated, langOriginal, langCode, kind ("asr" for auto captions),
	                         url or fileContent
	chapter         array<dictionary> : title, and time (milliseconds, string) or time_second (seconds or hh:mm:ss, string)

------------------------Web page messages----------------------------------
Pages shown in PotPlayer's WebView2 browsers (broadcast list, chat window, web dialogs) can send these
messages with chrome.webview.postMessage(). Any page can send them; no extension registration is needed.
Inject the sending script with GetBroadcastListScript() or load it from your own page.

potPlayer.video-click
	chrome.webview.postMessage({ type: 'potPlayer.video-click', url: 'https://...' });
	Open url in PotPlayer (same as clicking a video link)

potPlayer.seek
	chrome.webview.postMessage({ type: 'potPlayer.seek', seek: '1m30s' });
	Seek the currently playing video to an absolute position. Ignored when nothing is playing
	seek can be a string or a number
		number            : seconds, e.g. 90, 90.5
		"90", "90.5"      : seconds
		"1h2m3s", "1m30s", "45s" : YouTube t= form (each part may have decimals)
		"01:02:03", "01:02:03.500", "02:03" : hh:mm:ss(.ms)
	Messages with an unparsable seek value are ignored
