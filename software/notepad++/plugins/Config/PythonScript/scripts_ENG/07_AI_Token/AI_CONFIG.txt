AI Feature Configuration Guide
========================================

【Configuration File】
ai_config.json (same directory) — or run configure_ai.py wizard

【Format】
{
  "api_type": "openai",
  "api_key": "your-api-key-here",
  "api_base": "https://api.deepseek.com/v1",
  "model": "deepseek-chat",
  "temperature": 0.7,
  "max_tokens": 2000
}

【Common OpenAI-compatible endpoints】
- OpenAI: https://api.openai.com/v1
- DeepSeek: https://api.deepseek.com/v1
- Qwen compatible: https://dashscope.aliyuncs.com/compatible-mode/v1

【Notes】
- api_base usually ends at /v1 (no /chat/completions)
- Keep secrets out of git; copy ai_config.json.example → ai_config.json
