RustDesk 是一个开源远程桌面应用程序，如果用户愿意，它允许用户托管自己的连接服务器（虽然不是必需的）。它是用 Rust（编程语言）编写的。在任何计算机上使用 RustDesk 都相当容易。 由于它既充当服务器又充当客户端，因此同一应用程序可用于本地计算机和远程计算机。

RustDesk 使用

RustDesk 是一个小文件，不需要提前安装或配置。您所要做的就是下载文件并通过双击可执行文件来启动它。该工具是半便携式的，这意味着它不需要安装，但会在您的系统中保留某些文件（在 AppData 中，一些配置 TOML 文件和有关先前建立的远程连接的日志）。因此，如果需要，可以在您的系统中轻松找到有关先前会话的日志和详细信息。

打开该工具后，您会注意到一个左侧面板，其中显示了您的设备用于远程访问的凭据——ID 和密码。 ID 是唯一的，但可以通过单击自动创建新识别码的随机发生器来更改密码。要建立新的远程连接，您必须在另一台 PC 上安装 RustDesk，并在其中插入您希望访问的机器的唯一 ID 和密码。

此外，重要的是要添加所有会话都已注册，并且作为向您显示您创建的所有盒子会话的虚拟机面板，RustDesk 将为您访问的所有计算机创建不同的实例，通过它们的操作系统和独特的引用它们识别码。
