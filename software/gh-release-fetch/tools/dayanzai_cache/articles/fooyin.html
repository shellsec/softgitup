在流媒体音乐大行其道的当下，仍有一群硬核乐迷执着于本地无损音质与极致的操作体验。近日，面向本地音乐爱好者的高度可定制播放器 fooyin 持续迭代更新，凭借极致灵活的界面定制、全面的音频格式支持与强大的扩展能力，成为 Linux 平台上备受关注的开源音乐工具，多平台适配也在稳步推进中。

fooyin 是一款以定制化为核心的桌面音乐播放器，主打本地音乐库管理与高保真播放体验，项目依托 Qt 框架开发，采用 FFmpeg 作为解码后端，兼顾轻量化运行与专业音质表现。

fooyin 中文版

区别于传统播放器固定布局，fooyin 提供布局编辑模式，支持从零开始搭建界面，或选用预设模板快速上手。用户可自由组合波形进度条、专辑封面、播放列表、目录树、标签面板等组件，搭配自定义快捷键，打造独一无二的操作界面。

面向高阶用户，软件内置 FooScript 脚本语言，可实现控件行为、动态列表、显示逻辑的深度配置；配合插件系统，支持解码、音效、可视化、第三方集成等能力扩展，满足从普通用户到发烧友的全场景需求。

fooyin 并非传统的开箱即用型播放器，而是一款围绕自定义构建的音乐管理工具。它不预设固定的使用逻辑，而是提供了一个空白的画布。

用户可以通过进入布局编辑模式，从零开始构建界面，或者利用预设布局进行微调。无论是极简的迷你模式，还是复杂的多栏控制台，fooyin 都能通过其丰富的小部件系统实现。此外，软件内置了名为 FooScript 的脚本语言，允许高级用户对小部件进行深度编程配置，甚至可以通过插件系统来扩展功能。

对于发烧友而言，fooyin 的内核素质同样出色。根据官方文档，该播放器支持目前市面上绝大多数主流音频格式，包括 FLAC、MP3、WAV、AIFF 等，并特别强调了对 VGM（视频游戏音乐） 和 Tracker 模块格式的原生支持，这在同类软件中较为罕见。

fooyin 具备完善的本地库管理能力：支持按任意字段筛选曲目、创建 / 编辑播放列表、导入导出 M3U/M3U8 列表；内置标签编辑器、目录浏览器与库树视图，方便快速归档与检索；支持自动抓取封面、同步歌词、播放统计与动态自动歌单，大幅提升整理效率。

foobar2000 的替代品？

fooyin 就是 Linux 用户寻找的 “那个” foobar2000。它完美继承了 foobar2000 “极简、高效、可无限定制”的灵魂与界面语言，解决了 Linux 上缺乏此类专业级、高自由度播放器的痛点。如果你是从 Windows 转来的 foobar2000 老用户，打开 fooyin 会有强烈的亲切感和 “回家” 的感觉，几乎无需学习即可上手。

fooyin 从设计理念、界面风格到核心功能，都明显受到了 foobar2000 的深度启发，甚至可以被看作是开源、跨平台（主打 Linux）的 “精神续作”。官方与社区也从不避讳这一点，直接将其定位为 foobar2000 inspired（受 foobar2000 启发）的播放器。

目前，Fooyin 由开发者 Luke Taylor 独立维护，fooyin 优先支持 Linux 系统，Windows 已推出测试版，macOS 等平台适配正在开发，未来将实现跨平台覆盖。项目保持高频更新，近期 v0.10.x 版本新增 DSP 音效、均衡器、曲目渐变、Discord 状态同步等功能，稳定性与易用性持续优化。
