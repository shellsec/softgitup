Tabby（原 Terminus）是一个高度可配置的终端仿真器、SSH 和串行客户端，适用于 Windows、macOS 和 Linux。

Tabby 功能特色

  • 集成 SSH 和 Telnet 客户端和连接管理器
  • 集成串口终端
  • 主题和配色方案
  • 完全可配置的快捷键和多和弦快捷键
  • 拆分窗格
  • 记住你的标签
    PowerShell（和 PS Core）、WSL、Git-Bash、Cygwin、MSYS2、Cmder 和 CMD 支持
  • 通过 Zmodem 从/向 SSH 会话直接传输文件
  • 完整的 Unicode 支持，包括双角字符
  • 不会因快速流动的输出而窒息
  • Windows 上的正确 shell 体验，包括选项卡完成（通过 Clink）
  • 用于 SSH 机密和配置的集成加密容器
  • SSH、SFTP 和 Telnet 客户端可作为 Web 应用程序使用（也是自托管的）

Tabby 是什么，不是什么

Tabby 是 Windows 标准终端 (conhost)、PowerShell ISE、PuTTY、macOS Terminal.app 和 iTerm 的替代品

Tabby 不是新的 shell 或 MinGW 或 Cygwin 的替代品。 它也不是轻量级的 – 如果 RAM 使用很重要，请考虑 Conemu 或 Alacritty

终端功能

  • 一个V220终端+各种扩展
  • 多个嵌套拆分窗格
  • 窗口任意一侧的选项卡
  • 带有全局生成热键的可选可停靠窗口（“Quake 控制台”）
  • 进度检测
  • 流程完成通知
  • 括号粘贴，多行粘贴警告
  • 字体连字
  • 自定义外壳配置文件
  • 可选的 RMB 粘贴和复制选择（PuTTY 样式）

SSH 客户端

  • 带有连接管理器的 SSH2 客户端
  • X11 和端口转发
  • 自动跳转主机管理
  • 代理转发（包括 Pageant 和 Windows 原生 OpenSSH 代理）
  • 登录脚本

串行终端

  • 已保存的连接
  • Readline 输入支持
  • 可选的十六进制逐字节输入和十六进制转储输出
  • 换行符
  • 自动重新连接

请注意，该实用程序仍处于 Alpha 开发阶段，因此可能会出现一些错误。不过，这个应用程序值得称赞，但是，它绝对远非完美。

遗憾的是，Windows 用户无法使用 Tab Persistence 功能（至少目前如此）。就像大多数基于 Electron 的应用程序一样，Terminus 也遭受高资源消耗问题的困扰，它也不是完全轻量级的。

不过，归根结底，有一点很清楚，对于大多数认为 CMD 和 PowerShell 几乎是令人讨厌的东西并且认为它们不值得的 Windows 用户来说，这个应用程序肯定会起到作用。

Tabby 是一款免费的终端仿真器，它的主要特点是轻量级、易于使用和高度可定制。Tabby 支持多个标签页，可以同时打开多个终端会话，方便用户进行多任务操作。此外，Tabby 还支持多种主题和颜色方案，用户可以根据自己的喜好进行个性化设置。

总的来说，Tabby 是一款功能简单但实用的终端仿真器，适合需要在 Windows 系统上进行命令行操作的用户使用。它的界面简洁明了，易于使用，同时支持多个标签页和个性化设置，可以满足不同用户的需求。虽然 Tabby 的功能相对较少，但它的轻量级和易于使用的特点使得它成为一款备受欢迎的终端仿真器。
