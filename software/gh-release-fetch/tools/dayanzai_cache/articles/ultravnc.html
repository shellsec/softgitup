UltraVNC 中文版由大眼仔旭独家汉化发布。UltraVNC 中文版是一款功能强大、易于使用且免费的远程电脑访问软件，它可以在您自己的屏幕上显示另一台计算机的屏幕（通过互联网或网络）。该程序允许您使用鼠标和键盘远程控制其他计算机。这意味着您可以像坐在远程计算机前一样，在当前位置工作。

VNC（Virtual Network Computing）是一种远程帧缓冲协议（RFB），它允许通过互联网远程查看和控制桌面。在共享桌面的计算机上必须运行 VNC 服务器，在访问共享桌面的计算机上必须运行 VNC 客户端。

UltraVNC 中文版

什么是 UltraVNC？

UltraVNC 是远程支持软件，可以显示另一台计算机的屏幕，允许通过互联网或网络共享和控制屏幕，传输文件并快速通信。 它为用户提供便利，帮助解决服务台问题，更快地传递信息并共享桌面文件。

该软件具有快速聊天、加密、与各种 VNC 风格兼容以及文件传输等关键功能。 UltraVNC 是 Ultra Virtual Network Computer 的缩写，由 Tristan Richardson 于 1999 年创立，总部位于美国。

UltraVNC 和 TightVNC 都是免费的开源远程访问和屏幕共享软件。 它们允许您查看远程计算机的桌面并使用本地鼠标和键盘控制它。 UltraVNC 和 TightVNC 利用 VNC（虚拟网络计算）系统，这是一种利用远程帧缓冲协议的图形桌面共享系统，提供高品质的远程桌面监控服务。

UltraVNC 与 TightVNC 比较

UltraVNC 和 TightVNC 是提供类似功能的免费工具。 如果您在 UltraVNC 和 TightVNC 之间做出选择时遇到困难，您可能想了解 TightVNC 和 UltraVNC 之间的区别。 以下是 UltraVNC 和 TightVNC 在兼容性、安全性、速度和功能方面的完整比较。

兼容性

UltraVNC 主要支持 Windows 操作系统，包括 Windows 95**/98**/Me**/NT4**、Windows XP、Windows Vista、Windows 7/8/8.1/10/11、Windows Server 2003/2003 R2/ 2008/2008 R2/2012/2012 R2/2016/2019/2022。在任何支持 Java 的平台（Linux、Mac OS 等）上运行的简单 Web 浏览器可以使用嵌入式 Java 查看器连接到 UltraVNC 服务器并传输文件 。

TightVNC 在 Windows XP 及所有更高版本上运行，包括 Windows XP/Vista/7/8/8.1/10/11 以及相应版本的 Windows Server。 因此，TightVNC 几乎可以与任何 Windows 版本一起使用（支持 32 位和 64 位系统）。 请注意，在 Windows XP 上，您应该安装最新的 Service Pack。

安全

UltraVNC 采用 DiskStation Manager (DSM) 加密，允许查看器和服务器建立安全通信链路，防止未经授权的访问。 但UltraVNC存在安全漏洞。 例如，版本 1211 中的 VNC 服务器代码存在多个内存泄漏 (CWE-665)，允许攻击者读取堆栈内存并利用它来泄露信息。 与另一个漏洞结合使用，该漏洞可用于读取堆栈内存并绕过 ASLR。

尽管 TightVNC 对通过网络发送的 VNC 密码进行加密（VNC 使用 DES 加密的质询响应方法进行密码加密，其中密码限制为 8 个字符，有效 DES 密钥长度为 56 位），但其余流量仍会发送 未加密。 因此，通过 Internet 使用 TightVNC 可能会带来安全风险。 为了解决这个问题，TightVNC 团队计划在 TightVNC 的未来版本中实现内置加密。 此外，还建议安装 SSH 服务器并对来自不受信任网络的所有 TightVNC 连接使用 SSH 隧道以提高安全性。

速度

让我们看一下 TightVNC 与 UltraVNC 的速度。 实际上，UltraVNC 和 TightVNC 都针对速度进行了优化。

如果使用 UltraVNC，建议您安装其镜像驱动程序。 因此，控制会话变得非常流畅且无闪烁。

为了更好地支持较慢的网络连接，TightVNC 服务器和查看器采用了专门的数据编码技术。

功能特色

UltraVNC 允许您在查看器和服务器之间传输文件和文件夹。 它还会在传输之前压缩文件和文件夹，让您以最小的带宽获得最大的灵活性。 此外，UltraVNC 还具有嵌入式文本聊天系统，具有直观的图形用户界面 (GUI)，允许本地（查看器）和远程（服务器）计算机之间轻松快速地进行通信。

凭借其独特的功能（例如会话共享），TightVNC 可能是满足您的远程管理需求的最佳选择。 默认情况下，TightVNC 在创建新会话时会断开现有远程会话。 可以更改此设置以允许多个远程用户同时查看和控制服务器。 或者，您可以阻止新的远程会话，直到第一个会话完成。 此外，它还支持无人值守的远程访问和文件传输。

常见问题 (FAQ)

它是最好的远程支持系统吗？

UltraVNC 在其类别（远程支持系统）的 19 个软件中排名第 5。

它是一个易于使用的软件吗？

是的，UltraVNC 使其相当易于使用。 该产品用户友好且直观。

是基于云的吗？

不，该软件不是基于云的，因此您需要在本地安装它并将其直接连接到服务器。

可以在手机上使用吗？

不可以，目前 UltraVNC 无法在移动设备上访问，您需要从计算机上访问它。

UltraVNC 适合您或您的企业吗？

UltraVNC 适用于 IT 部门、个人、课堂控制和电子学习以及远程客户支持公司的小型、中型和大型机构。
