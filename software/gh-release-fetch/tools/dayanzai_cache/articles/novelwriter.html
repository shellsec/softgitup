novelWriter 中文版是一款功能强大、易于使用的开源小说创作工具，它结合了 Web 应用程序和命令行工具，让写作过程变得更加高效、有序且富有乐趣。通过其强大的功能特点和跨平台支持，novelWriter 成为小说创作者不可或缺的工具之一。

如果您是一位小说创作者，那么 novelWriter 值得您去尝试。

novelWriter 中文版

novelWriter 功能特色

通过 novelWriter，您可以以任何您需要的方式将您的小说分解成任意数量的文档。它们可以拖放到自定义的顺序中，并组织成文件夹。文档甚至可以有子文档。

通过文档和笔记中方便的元关键字/值标签，可以定义与项目笔记的交叉引用。您还可以插入注释，将其包含在手稿中。

其他小说概述
当您按章节和场景编排好小说的主要部分后，可以切换到 “小说大纲 ”视图。

通过 “小说大纲 ”视图，您可以用标题而不是文档文件来查看小说的完整结构。您仍然可以像在常规的项目树中一样，打开每个章节或场景进行编辑。

项目大纲
通过大纲视图，您可以全面了解小说的章节和场景结构。

它还会以列的形式显示所有相关的元数据和交叉引用。默认情况下会显示一组列，但您可以通过工具栏上的配置按钮添加更多列。

构建和导出
通过 “构建手稿 ”工具，您可以将所有文件汇集到一个文档中。您可以筛选要包含的内容以制作手稿，制作小说大纲草稿，或将所有笔记汇编成文档。

结果可以打印或保存为 HTML、Open Document 和 Markdown 格式。大多数开源和商业文字处理器都支持开放文档格式。您还可以打印手稿，包括打印为 PDF。

深色主题和语法
novelWriter 默认使用 Qt 框架的默认颜色主题。但它也提供了一个可选的标准深色主题。所有主题都有基于 Typicons 图标集的匹配图标主题。

此外还有一些用户贡献的主题，你也可以创建自己的主题。

此外，你还可以为文本编辑器和查看器选择一些浅色和深色语法高亮主题。这些主题与图形用户界面主题分开选择，因为它们数量更多。

其他功能

文档查看器
任何文档，包括你正在编辑的文档，都可以在单独的视图面板中并行查看。

编辑器焦点模式
在聚焦模式下，编辑器会覆盖整个窗口，隐藏项目树和视图面板，让你专注于文本。

跟踪链接和参考文献
在查看器中可点击标签和参考资料，在编辑器中可通过控制点击标签和参考资料，这样你就可以在写作时快速浏览笔记。
在视图面板中打开的文档也会在底部的参考资料框中列出指向它的所有其他文档。
