OpenScreen 中文版

为何选择 OpenScreen？

OpenScreen 的诞生，源于对一款强大且免费的录屏工具的渴望。它并非是商业软件的简单克隆，而是专注于为用户提供最核心、最实用的功能，让你无需支付一分钱，就能享受到高品质的录屏体验。

完全免费，毫无保留
OpenScreen 遵循 MIT 开源许可证，这意味着它不仅是免费的，而且你可以自由地使用、修改和分发。无论是个人项目还是商业用途，它都不会向你收取任何隐藏费用或订阅金，让你的创作毫无后顾之忧。

专业品质，一键生成
它的核心优势在于能让你的录屏作品看起来更具“设计感”和专业度。通过内置的自动缩放特效，软件可以智能跟随你的鼠标光标，自动放大关键操作区域，引导观众视线，让你的演示视频告别平铺直叙，瞬间提升质感。

本地处理，安全私密
在这个数据安全至关重要的时代，OpenScreen 坚持所有录制和处理过程均在你的本地设备上完成。你的视频数据绝不会上传至任何服务器，从根本上保障了个人隐私和商业机密的安全。

强大功能一览

OpenScreen 虽然定位简洁，但其功能却相当全面，足以满足绝大多数创作者的需求。

1. 基础录屏：清晰稳定，全面覆盖
支持全屏、指定窗口、自定义区域三种录制模式，可同步录制麦克风语音与系统音频，搭配摄像头画中画叠加功能，支持拖拽定位与形状调整，轻松实现人像与屏幕画面同框录制，满足教程、直播回放等多元场景。

2. 自动缩放：突出重点，视觉更聚焦
自带智能光标跟随缩放功能，可自定义 1.25x 至 5x 多档缩放比例，自动突出关键操作区域，搭配运动模糊效果，让缩放与平移过渡更流畅，提升视频观感与信息传递效率。

3. 视觉美化：精美包装，提升质感
内置精选壁纸、纯色、渐变背景，也支持上传自定义背景，可调整阴影、圆角、内边距等样式；同时提供裁剪、修剪、片段调速、模糊遮挡敏感信息等剪辑能力，无需额外工具即可完成视频精修。

4. 标注互动：信息清晰，易懂直观
支持添加文字、箭头、高亮、图片等标注元素，搭配光标与点击高亮效果，让操作步骤一目了然，大幅降低观众理解成本，适合教程、产品说明等内容制作。

5. 导出灵活：多格式适配，无水印束缚
支持导出MP4、GIF、WebM三种格式，可自定义分辨率、比例与画质，全程无水印，导出视频可直接用于社交平台、官网、文档等场景，完美适配个人创作与商业推广需求。

轻松安装与使用

获取和安装 OpenScreen 非常简单，项目在 GitHub 上非常活跃，你可以通过多种方式快速上手。

下载安装：前往项目的 GitHub Releases 页面 下载对应你操作系统的安装包。

包管理器安装：

  • macOS：使用 Homebrew，命令为 brew install –cask siddharthvaddem/openscreen/openscreen。
  • Windows：使用 winget，命令为 winget install SiddharthVaddem.OpenScreen。
  • Linux：支持通过 .deb、.pacman 包安装，或直接使用 .AppImage 文件运行。

安装后，首次运行可能需要你授予屏幕录制和麦克风等权限，根据系统提示操作即可。
