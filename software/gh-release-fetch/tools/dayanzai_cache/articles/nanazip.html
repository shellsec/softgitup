NanaZip 中文版由大眼仔旭发布。随着新 Windows 11 的到来，系统操作的基本方面发生了许多变化。我们不仅有一个新的“开始”菜单或一个新的文件资源管理器，而且在以相同的方式执行我们多年来一直在做的事情时，它们的行为也不同。

其中一件事是在桌面上右键单击、在资源管理器中或选择文件时发生的情况。在 Windows 11 中，右键单击不会显示第三方应用程序的选项，例如 7-zip 或 Winrar 的应用程序，以压缩或解压缩文件，您必须单击“显示更多”。但是，如果应用程序本身更新以集成到新的右键单击菜单中，则这是有解决方案的。

NanaZip 中文版

NanaZip 产品特点

  • 继承 7-Zip 21.07 的所有功能。
  • 使用 MSIX 打包以获得现代部署体验。
  • 支持 Windows 10/11 文件资源管理器中的上下文菜单。
  • 为 NSIS 档案启用 NSIS 脚本反编译支持。 （从 7-Zip NSIS 分支合并。）
  • 提供 7-Zip 执行别名，帮助用户迁移到 NanaZip。
  • 支持 Brotli、Fast-LZMA2、Lizard、LZ4、LZ5 和 Zstandard 编解码器。 （从 7-Zip ZS 分支合并。）
  • 支持所有 GUI 组件的 Per-Monitor DPI-Aware。
  • 支持 i18n for GUI 版本的自解压可执行文件。

7-Zip 的衍生产品，带来现代 Windows 体验

这基本上就是 NanaZip 项目所做的，它是许多人最喜欢的开源的衍生物：7-Zip，并且已经迅速出现在我们现在在 Windows 11 中改进的右键单击菜单中。

这似乎是一件小事，但是如果我们不断压缩和解压缩文件，毫无疑问，可以节省我们无数次单击“显示更多选项”并浏览 Windows 11 隐藏的第二个右键单击菜单，这与Windows 10完全相同。

NanaZip 是一个正在开发中的项目，存在一些小的已知问题，但正在努力解决这些问题。该应用程序的路线图计划进一步使UI现代化，以使用 WIndows 11 风格的控件，并提供对 Mica 以及明暗模式的完全支持。

现在，如果您是那些喜欢旧的 WinRAR 的人之一，那么您将很高兴知道最新的测试版还支持 Windows 11 的新右键单击菜单。

系统要求

支持的操作系统：Windows 10 版本 1809 或更高版本

支持的平台：x86、x86-64(AMD64) 和 ARM64。
