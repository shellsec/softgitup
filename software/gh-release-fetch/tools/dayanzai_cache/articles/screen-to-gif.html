ScreenToGif 使用方法

  1. 打开 ScreenToGif 应用程序。
  2. 点击“录制”按钮以开始录制。
  3. 在屏幕上进行您想要捕捉的操作或动画。
  4. 点击“停止”按钮来停止录制。
  5. 在编辑器中编辑你的 GIF，你可以添加文本、插入帧、裁剪、调整尺寸、更改播放速度等等。
  6. 完成后，点击“保存”按钮将 GIF 保存到您的计算机中。
