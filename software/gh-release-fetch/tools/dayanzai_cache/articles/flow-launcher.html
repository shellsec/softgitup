开源 Windows 搜索和启动工具 Flow Launcher 中文绿色版由大眼仔旭发布。Flow Launcher 是一款适用于 Windows 操作系统的快速应用程序启动器和工具。它允许用户通过关键字搜索和快捷键启动应用程序、文件夹、以及各种任务和操作。此外，Flow Launcher 还集成了许多有用的功能，例如剪贴板历史记录、计算器、翻译和网络搜索等。Flow Launcher 还支持用户创建自定义插件和脚本来扩展其功能。

Flow Launcher 中文版

Flow Launcher 功能特色

  • 快速启动应用程序和任务: Flow Launcher允许用户通过快捷键或关键字快速启动应用程序、文件夹和网页，从而提高工作效率。
  • 智能搜索和匹配: 能智能地搜索并匹配您计算机上的文件、文件夹、应用程序和其他资源。它还支持模糊搜索和通配符搜索等高级搜索方式。
  • 剪贴板历史记录: 可以跟踪您最近复制的文本内容，并将其存储在剪贴板历史记录中。这使您能够轻松地回顾之前的拷贝记录。
  • 系统命令和设置: 还集成了一些常用的系统命令和设置选项，如音量调节、屏幕亮度、网络设置和电源管理等。
  • 计算器和单位转换: Flow Launcher 中内置了基本的计算器，并支持各种单位转换（如长度、面积、重量、时间和货币）。
  • 自定义插件和脚本: 支持用户创建自定义插件和脚本来扩展其功能，例如添加新的搜索引擎、快速打开特定网站等等。
  • 网络搜索: 允许您在各种搜索引擎（如谷歌、百度、必应等）中进行快速搜索。只需输入搜索关键字，就可以在默认搜索引擎或选择的其他搜索引擎中搜索内容。
  • 自动完成和建议: 当您开始输入命令或关键字时，Flow Launcher 会自动提供匹配建议和选项，以帮助您更快地找到所需的应用程序、文件或任务。
  • 主题和样式定制: 允许用户根据自己的喜好自定义主题和样式，例如更改背景颜色、字体、图标等。
  • 快捷方式管理: 可以帮助您管理和查看计算机上的所有快捷方式，并将其分类保存。您可以通过 Flow Launcher 轻松访问和使用这些快捷方式。
  • 多语言支持: Flow Launcher 支持多种语言，包括英语、中文、日语、德语、法语等等。

如何使用 Flow Launcher 启动应用程序

Flow Launcher 可以轻松搜索和打开几乎任何内容，包括应用程序。无需在开始菜单应用程序列表中寻找；只需搜索、单击和打开。

按您在设置过程中选择的热键打开 Flow Launcher 窗口。如果您觉得这很尴尬或难以按压，您可以在设置中更改它。

开始键入应用程序的名称。在键入之前，您不需要单击搜索框，因为 Flow Launcher 在打开时将处于焦点状态。

在列表中看到所需的应用程序后，您可以单击它将其打开或按显示的快捷方式，例如 Alt + 2。

如何更有效地搜索文件

Flow Launcher 非常适合搜索您的 PC。它设法找到 Windows 搜索可以找到的所有内容，但以更轻松、更高效的方式显示结果。

  1. 在 Flow Launcher 窗口中键入以开始搜索。结果在标题旁边显示一个图标，以便于判断它是什么。它可以查找应用程序、文件、设置、图像等。然后，您可以单击要打开的结果或按显示的键盘快捷键。
  2. 如果 Flow Launcher 在您的计算机上找不到匹配的文件、应用程序或设置，它将改为提供 Google 搜索查询。单击此按钮将在您的默认浏览器中打开一个用于 Internet 搜索的新选项卡。
  3. 在 Flow Launcher 中，有几种方法可以优化搜索。例如，要在特定网站上搜索内容，您可以在搜索查询中包含网站名称，例如 YouTube David Bowie。
  4. 要搜索浏览器书签，请使用 b 开始搜索查询。例如： b 如何在 excel 中创建工作簿。
  5. 如果要运行 Powershell 命令，请键入 >，然后键入 Powershell 命令。例如：> ping 192.168.1.1。
  6. 您甚至可以使用它来执行简单的计算。键入 5*5 可查看 5 乘以 5 等于什么。您可以使用的其他数学符号包括 +（加）、-（减）和 /（除以）。
  7. 如果要在特定目录中搜索，请在百分比符号之间键入目录名称，例如 %programfiles%\。您还需要包含一个尾部反斜杠。
  8. 当您开始使用 Flow Launcher 时，您可能会看到允许 Web 搜索插件等结果。这将激活 Flow Launcher 中可用的现有插件。您还可以从商店下载并安装额外的插件。

如何使用 Flow Launcher 插件添加额外功能

Flow Launcher 中已经安装并激活了多个插件。您可以随时在设置中启用和禁用这些。您还可以轻松添加额外的插件以进一步扩大实用程序的范围。

  1. 打开 Flow Launcher 设置，然后选择插件商店选项卡。
  2. 滚动浏览可用插件列表以找到要添加的插件。
  3. 单击插件名称，然后单击安装按钮。
  4. Flow Launcher 窗口将打开，并搜索该插件。单击结果并同意弹出消息中的安装。
  5. 该插件将添加到插件列表中，您可以在其中根据需要启用和禁用它。

卸载 Flow Launcher

如果您在 PC 上安装了 Flow Launcher，则可以像卸载任何其他应用程序一样卸载它。如果您需要一些帮助，请查看我们的指南 如何在 Windows 上卸载程序.

当然，如果您决定在便携模式下使用 Flow Launcher，则无需卸载它。如果您在此模式下使用该实用程序，则值得在设置中启用 Portable Mode 选项。这可确保所有搜索数据和设置都存储在单个文件夹中，从而使这些数据同样具有可移植性。

使用 Flow Launcher 提高 Windows 中的工作效率

Flow Launcher 是一个外观简单的工具，可能会让您想知道为什么需要另一个搜索框。但是深入挖掘，您应该很快就会看到它有多么强大和有用。如果您正在寻找提高 Windows 10 或 11 工作效率的方法，这是一个很好的起点。
