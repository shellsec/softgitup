PCSX2 是一款免费的开源 PlayStation 2 (PS2) 模拟器。其目的是模拟 PS2 的硬件，使用 MIPS CPU 解释器、重编译器和虚拟机的组合来管理硬件状态和 PS2 系统内存。这允许您在 PC 上玩 PS2 游戏，并具有许多附加功能和优势。

PCSX2 项目已经运行了二十多年。过去的版本只能运行一些公共领域的游戏演示，但较新的版本可以全速运行大多数游戏，包括《最终幻想 X》和《鬼泣 3》等热门游戏。访问 PCSX2 兼容性列表以查看游戏的最新兼容性状态（已测试超过 2500 款游戏）。

PlayStation 2 模拟器

PlayStation 2 仍然是有史以来最畅销的游戏机，也是游戏玩家最欣赏的硬件。当时，PS2 的推出令人惊讶，以至于没有多少人预料到它会被地球上一半的人使用。上述产品是一款革命性的热门产品，引入了几种新机制、改进的图形和一系列至今仍在探索的新类型。

然而，即使在游戏机停产后，它仍然留在许多人的记忆中。这种热情激励了忠实的粉丝们努力工作，并创建了一个模拟器，为那些错过了那个时代一些游戏的人或刚刚发现游戏机的人打开了大门。这个模拟器被称为 PCSX2。

请注意，这个模拟器在低端电脑上可能无法流畅运行。虽然有些游戏可以运行，但其他游戏可能难以以可接受的速度运行。

什么是 PCSX2？

PCSX2 是一款免费的开源 PS2 模拟器，最初于 2002 年 3 月 23 日发布。在早期，该模拟器很难有效地运行游戏。然而，多年来，它得到了显著的改进，能够以不错的速度运行许多游戏，尽管有一些小问题。

与实际的 PS2 控制台相比，使用 PCSX2 的主要优势之一是它能够提供高达 4096×4096 的自定义分辨率，以及纹理过滤和抗锯齿等功能。这可以改善图形，有时可以超越其他重制版游戏的质量。这是对模拟器功能的非凡证明。

背景与发展

PCSX2 最初由 PCSX-Reloaded 的开发者 Linuzappz 与 Shadow 于 2001 年开始开发，之后其他开发者加入。2002 年 3 月发表第一个测试版本 0.026 版，能够加载一些游戏，尽管速度并不理想。经过对核心、BIOS 模拟的完善，2006 年 7 月发布 0.9.1 版。

2007 年到 2011 年这五年间，开发者主要提升模拟速度，实现网络对战。0.9.8 版于 2011 年 5 月发布，该版本带来了使用 wxWidgets 重构的 GUI 界面，全新的 VU（向量处理器）重编译器、内存卡编辑器、全新的 SPU2-X 音频插件等改进，提升了兼容性。2012 年 8 月 3 日发表第一个正式版本 1.0.0 版。

PCSX2 就像它的前身 PCSX 一样，是以插件（plugin）为基础的架构，从核心模拟器分门别类出好几个功能：功能有图形处理、控制器、光盘驱动器，还有 USB、音效和 IEEE 1394（i.Link）端口。不同的插件，在兼容性和功能上可能会产生出不同的效果。

此外，由于其相关的著作权考量和法律问题，PCSX2 需要自行从 PS2 主机提取 BIOS 文件，开发团队不提供 BIOS 文件下载。2016 年 9 月起，PCSX2 能够通过 PSX 模式兼容部分 PlayStation 的游戏。

64位延伸

由于 64 位处理器快速发展和普及化，PCSX2 研发团队积极地开始设计 64 位处理器的模拟组件，尽可能地加快 PCSX2 的执行速度。但目前 32 位程序能提供更好的性能。

PCSX2 安全吗？

PCSX2 模拟器完全安全。无论听起来多么诱人，请务必从官方网站下载，而不是从其他地方下载。始终坚持使用官方网站。

模拟器仍然处于活动状态，并且每隔一段时间就会发布开发版本供公众测试和报告任何更改。老实说，使用这个模拟器你没有什么可担心的。

技术说明

  • 需要 Visual C++ 2019 x64 可再发行组件才能在 Windows 上运行 PCSX2。
  • Windows XP 和 Direct3D9 支持在稳定版本 1.4.0 之后被删除。
  • Windows 7、Windows 8.0 和 Windows 8.1 支持在稳定版本 1.6.0 之后被删除。
  • 在稳定版本 1.6.0 之后，32 位和 wxWidgets 支持被删除，wxWidgets 代码于 2022 年 12 月 25 日被完全删除。
  • 请务必更新您的操作系统和驱动程序，以确保您获得最佳体验。还建议使用较新的 GPU，以便您拥有最新的受支持驱动程序。
  • 由于版权问题以及尝试解决该问题的复杂性，您需要从合法拥有的 PS2 主机中提取 BIOS 转储才能使用模拟器。有关 BIOS 以及如何从主机获取 BIOS 的更多信息，请访问此页面。
  • 默认情况下，PCSX2 使用两个 CPU 内核进行仿真。第三个核心可以通过 MTVU speed hack 使用，它与大多数游戏兼容。对于具有 3+ 个内核的 CPU，这可能是一个显着的加速，但对于 GS 限制的游戏（或少于 2 个内核的 CPU）来说，这可能是一个减慢的速度。然后，软件渲染器将额外使用它设置为的渲染线程数，并且需要更高的内核数才能高效运行。
  • 需求基准测试基于 Passmark CPU 基准测试软件的统计数据。当我们说“STR”时，我们指的是 Passmark 的“单线程评级”统计数据。您可以在 Passmark 的网站上查找您的 CPU，了解它与 PCSX2 的要求相比如何。
  • Vulkan 需要最新的 GPU 驱动程序;旧驱动程序可能会导致图形问题。

最新消息

自上次稳定的 PCSX2 修订版发布以来，已经过去了四年多。四年内可能会发生很多事情，但我们无法预测在那段时间里会取得多大的进展。PCSX2 已收到超过 6000 次更改，下载量超过 1 亿次，并庆祝其成立 20 周年！有很多设计更改、技术发现等等需要讨论。让我们直接进入，从四年开发的亮点开始。

PCSX2进入Qt时代

你可能知道wxWidgets这个名字，因为它是PCSX2选择的GUI，或者是从其他模拟器（如Dolphin）那里知道的，它在迁移到Qt之前就使用了它。很长一段时间以来，它为我们提供了足够的服务，但它的年龄和实施开始很快显现出来。线程问题导致死锁和争用条件，因为它没有与仿真核心正确分离。技术债务开始时很高，随着项目试图继续推进，情况只会变得更糟。

但是现在，wxWidgets已经消失了。不再有桌面体验提醒你 2006 年的 Windows 桌面应用是什么样子。Qt带来了光滑的外观，更高效的UI后端，并提供了重做我们所有菜单和小部件的绝佳机会。添加主题可让您根据自己的喜好个性化您的 PCSX2。结果是迄今为止我们最好的用户体验。非常感谢 Stenzek 从 DuckStation 带来了他的 Qt 专业知识，并引领了 PCSX2 的新 Qt 设计！

告别插件

我们在插件方面做得很好，但他们的时代已经到来。作为更简单时代的遗物，插件曾经被誉为没有单一的优秀解决方案来应对仿真挑战的解决方案。不喜欢一个插件的设计？使用另一个。一个插件破坏了游戏？使用另一个。但是在准确性至上、用户体验日益重要的现代时代，它们的局限性、开发空间的碎片化和过时的代码库已经显示出它们的年龄。是时候说再见了，GovanifY率先推动了这一重大发展。

必须做出一个艰难的决定：我们如何摆脱插件，同时保持与它们曾经拥有的功能平价？摆脱插件可以解决许多问题，但如果功能或准确性丢失，它会带来更多问题。双方达成了一个中间立场：联系了插件作者，并将他们的代码同化到核心 PCSX2 项目中。这意味着该程序可以从单个项目文件构建而成;插件不再是单独编译和动态链接的！您会发现 PCSX2 的设置现在的工作方式有很多相似之处，但也有很多不同之处。许多常用术语和选项仍然存在，而其他术语和选项已被升级、更改或删除以跟上时代的步伐。

通过自动游戏修复简化配置

该团队的首要任务是专注于自动化。有多少事情需要用户处理，而他们真的不需要？答案是……好多。真的，很多。您可能还记得我们的旧界面在图形插件中隐藏了图形修复。或者也许是在自己的选项卡中处理的 CPU 模式。速度黑客还有另一个标签。更多的图形设置是他们自己的——不知何故没有连接到插件。游戏修复在某种程度上应该与其他所有内容不同……我们可以继续前进。这令人困惑。

但后来我们有一个想法：既然我们已经发布了一个包含游戏信息的数据库文件，为什么不包含更多关于游戏需要哪些设置才能正确运行的信息呢？因此，PCSX2的新“游戏索引”成为现实。它包含所有已知游戏的完整列表，通过此索引，我们现在提供预配置的修复程序，以确保您的游戏自动流畅运行。您不再需要记住在每次切换游戏时启用这些图形修复 – PCSX2 已经知道该游戏需要什么并为您完成！

再见金鱼大脑，你好每场比赛设置

wxWidgets的一个长期问题是每次切换游戏时都要更改设置。尽管自动游戏修复大多自行解决了这个问题，但您仍然可以进行任何个人接触。假设您想以不同的分辨率运行不同的游戏;这仍然是您每次切换游戏时都必须更改的内容，对吧？不再是了！

PCSX2 现在包括与全局设置分离的每游戏设置。默认情况下，每个游戏的设置将始终继承自您的全局设置，但它们允许您为特定游戏显式设置值。现在，如果您想以比其他游戏更高的分辨率运行游戏，或者为不同的游戏使用特定的存储卡，您可以在每个游戏的设置中设置一次，然后忘记它。
