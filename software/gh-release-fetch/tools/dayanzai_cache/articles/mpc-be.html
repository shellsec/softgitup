MPC-BE 中文版由大眼仔旭发布。MPC-BE 是一款用来播放 windows 系统里视频的万能视频播放器。它可以播放 vcd、rmvb、dvd、avi 等许多视频格式，俄罗斯程序员把该软件重新编写，使得 MPC-BE 的界面更加美观，让你尽情享受高品质的视觉和听觉的盛宴。它支持所有常见的视频和音频文件格式的播放。它是100%免费的，没有任何广告或后门。

轻量级开源媒体播放器 MPC-BE 中文版

MPC-BE 是从 MPC-HC 团队中分裂出来的俄国开发者们开发的一款基于 MPC-HC（1.6旧版）及 MPC（2006）的开源播放器。

MPC-BE 来由

最初 MPC-BE 只是 MPC-HC 的黑色 UI 版本，后来因为俄国开发者们和现在MPC-HC的项目管理XhmikosR意见不合，被XhmikosR赶了出来。随后毛子们决定在自己的论坛独立搞MPC-BE。

MPC-BE 播放器64位是 Windows 操作系统的 DVD 音频和视频文件。MPC-BE 播放器 64 位这个项目基于自己独立开发的原代码媒体播放器经典（Gabest）和媒体播放器经典 – 家庭影院（Casimir666）的基础上。MPC 有一个令人印象深刻的音频和视频过滤器，这使他能够播放几乎所有现有的媒体格式。

MPC-BE 播放器64位由于是开源软件，所以任何人都可以基于它的源代码进行修改，而MPC-BE在保留所有特点的基础上花功夫改进了UI部分，古老的98风格界面被漂亮的皮肤所取代，从而迎合了大众的审美观，也让老用户更加喜欢使用它。它具有播放控制，可以播放DVD。其他功能还包括的可能性在一个在线数据库中进行搜索字幕，播放列表支持，单帧，过滤器和阴影。它可以被配置为播放完毕后关闭/重新启动计算机。

MPC-BE 播放器功能特点

  • 支持多种视频、音频格式：可以播放几乎所有流行的视频和音频格式，如 MP4、AVI、MKV、FLAC、MP3、OGG 等，无需安装任何其他解码器。
  • 提供高质量视频播放：MPC-BE 使用 DirectShow 技术来播放媒体文件，具有卓越的音质和画质，同时支持硬件加速，可以更好地利用您的计算机资源。
  • 快速启动和低系统资源占用：MPC-BE 启动迅速，同时对 CPU 和内存的占用很少。即使在老旧的电脑上，也能快速启动并流畅播放。
  • 可自定义的外观和界面：用户可以通过选择不同的皮肤、字体和颜色方案，或者自己制作皮肤和背景，来定制独特而个性化的播放器。
  • 支持播放列表和书签功能：MPC-BE 提供了易于管理和操作的播放列表和书签功能，帮助您轻松访问您最喜欢的媒体文件。
  • 强大的快捷键支持：支持多达 167 种快捷键，让你可以非常方便地在视频播放中进行调整和控制。
  • MPC-BE 拥有简单的用户界面，界面美观，操作非常方便，支持自定义快捷键，拥有大量的功能，如缩放，截图，播放列表，字幕等。

如何评价 MPC-BE 播放器

  • 播放质量：MPC-BE通过使用DirectShow技术来播放媒体文件，具有卓越的音质和画质，同时支持硬件加速，可以更好地利用计算机资源。因此，播放质量是MPC-BE评价中很重要的指标之一。
  • 易用性：MPC-BE非常易于使用，可以快速启动，同时拥有简单、直观的界面和方便的操作。如果MPC-BE的易用性高，那么用户使用过程中会非常舒适和愉悦。
  • 格式支持：MPC-BE可以播放几乎所有流行的视频和音频格式，如MP4、AVI、MKV、FLAC、MP3、OGG等，无需安装任何其他解码器。如果MPC-BE支持的格式越多，那么就越能满足用户的多样化需求。
  • 资源消耗：启动迅速，同时对 CPU 和内存的占用很少。如果 MPC-BE 在使用时占用的计算机资源更少，那么它就更适合在性能较低的计算机上使用。
  • 功能特点：有许多其他的有用功能，如支持快捷键、自定义外观等。如果用户更喜欢这些额外的功能，那么就可以给 MPC-BE 更高的评价。

整体来说，MPC-BE 是一款很棒的多媒体播放器，完全免费而且功能强大，值得推荐。
