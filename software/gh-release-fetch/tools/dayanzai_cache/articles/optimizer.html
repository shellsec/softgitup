开源 Windows 10/11 系统优化工具 Optimizer 中文版由大眼仔旭整理发布。全新的 Windows 安装并不像许多用户想要的那样干净，因为最新版本的操作系统中包含的一些功能被认为是不必要的，会妨碍性能并损害您的隐私。Optimizer 是一个简单易用的应用程序，可让您禁用各种 Windows 功能、清理不必要的文件、从启动列表中删除项目、管理注册表等等。 它是完全可移植和开源的。

Optimizer 功能特色

  • 全语言支持（提供19种语言）
  • 提高系统和网络性能
  • 禁用不必要的窗口服务
  • 禁用 Windows 遥测、小娜等
  • 禁用 Office 遥测（仅适用于 Office 2016）
  • 禁用 Windows 10 自动更新
  • 一次快速下载有用的应用程序
  • 卸载 UWP 应用
  • 清理系统驱动器和主要浏览器的配置文件数据
  • 修复常见的注册表问题
  • 对 IP 进行 ping 操作并评估您的延迟
  • 在 SHODAN.io 上搜索 IP
  • 快速更改 DNS 服务器（从预制列表）
  • 刷新域名缓存
  • 删除启动时运行的有害程序
  • 编辑 Hosts 文件
  • 查找文件锁定句柄并终止关联的进程
  • 网络速度监控
  • 硬件检测工具
  • 在桌面上添加项目在右键单击菜单上
  • 为运行对话框定义自定义命令
  • 使用配置文件的静默运行支持

禁用可能会降低性能并影响您的隐私的 Windows 功能
该应用程序可以执行一些常规性能调整并禁用遥测、Windows Defender、网络节流、Skype 广告、错误报告等。该过程非常简单，但也提供了一些解释。

根据您的 Windows 版本，该程序还允许您执行一些特定于 Microsoft 操作系统特定版本的调整。这些在第二个选项卡中可用，但同样没有提供任何解释。

清理不必要的文件，删除不需要的启动程序并修复注册表问题
优化器可以通过删除可能不再需要的各种文件来帮助您释放磁盘空间，例如临时项目、日志和缓存文件。

此外，可以检查已添加到启动列表中的进程并删除您不希望自动启动的进程。

更重要的是，您可以使用这个程序来修复一些常见的注册表问题，它可以自动重新启动文件资源管理器以应用它们。

编辑您的 Hosts 文件并将新项目添加到上下文菜单
优化器可以轻松地在 Hosts 文件中添加新映射或删除它们，方法是插入单个项目或在高级编辑器中处理文件。

最后，此实用程序使您能够将自定义命令添加到右键单击上下文菜单，例如程序、文件夹快捷方式、网站链接或文件。

总而言之，Optimizer 是一个非常有用的应用程序，可以帮助您以各种方式优化 Windows、清理您的 PC 甚至自定义右键单击上下文菜单。它可以使用一些文档，但它很容易使用并且具有直观、简约的 UI。
