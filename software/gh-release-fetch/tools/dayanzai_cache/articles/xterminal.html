xTerminal 中文免费版由大眼仔旭发布。一个类似于 Linux 的 C# 中 Windows 终端，带有一些额外功能 :-)。xTerminal 是一种软件解决方案，它首先是开源的，可以轻松地集成到 Windows-Linux 开发或测试环境中。同时，该工具支持 C# 语法，更有效地满足开发者的需求。

xTerminal 中文版

谁可以使用此应用程序和用例场景
对于需要使用跨平台工具或操作系统的 Linux 开发人员和用户来说，xTerminal 是一个方便的解决方案。该应用程序支持从您的 Windows 操作系统中访问一个简单但功能齐全且实用的终端，该终端允许您使用 Bash 命令。

xTerminal 也非常适合 C# 开发人员。它允许您编写和编译给定的命令。您必须通过 MS 包管理器 NuGet，通过 Roslyn 为您的 C# 代码安装用于编译和使用代码分析方法的组件。

同时，您可以在 NeoVim 集成开发环境中使用该终端。 NeoVim 是一种软件解决方案，可充当解释器和代码编辑器，速度快且可定制。

可定制的用户界面和选项
与许多其他 Windows 终端（包括操作系统的嵌入式终端）一样，您可以通过“属性”窗口访问所需的自定义和设置窗口。

xTerminal 允许您更改光标大小、启用快捷功能、更改命令历史及其缓冲区大小、配置 UI（字体、文本和背景颜色等）等。

最后的考虑
xTerminal 是一个简约的解决方案，适合那些喜欢在舒适的空间内浏览系统和执行特殊命令的人。

半便携式应用程序是轻量级的，不会消耗太多系统资源。在程序的 GitHub 页面上，您可以浏览可用命令的整个列表。有关该项目的更多详细信息，您可以在 Github 上浏览 xTerminal 的可用命令和规范列表。

New Features
TermXT Editor (xte)
C# IntelliSense — full autocompletion and intellisense support for C# files in the xte editor
Real-time error syntax highlighting for TermXT code and
Roslyn code diagnostics — real-time error syntax highlighting and C# files via Roslyn
Multi-language syntax highlighting — added support for:
C# (.cs)
C / C++ (.c, .cpp, .h)
Rust (.rs)
JavaScript (.js)
Python (.py)
File Explorer — built-in file explorer (similar to fxp) accessible from within xte
Go to Line — jump to a specific line number directly in the editor
Search Next — navigate to the next search result using n or F3
Shift + Arrow selection — text selection with Shift+Arrow keys, with copy (Ctrl+C) and paste (Ctrl+V) support
Indentation — automatic indentation for new lines
Modified file check — editor warns when a file has unsaved modifications before closing or switching
ENV command execution — run environment (cmd/ps) commands directly from xTerminal without prefixing with cmd or ps. Alias commands will override ENV commands with the same name.
New Commands
xte — open files in the TermXT editor from the terminal
xclip — copy command output to the system clipboard
ver — display xTerminal version info and arhitecture directly from the terminal
