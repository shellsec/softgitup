PDF 拆分
PDF Arranger 是一款开源工具，可以帮助您修改、合并和拆分 PDF 文档。它可以执行一些功能，但请注意，它不是 PDF 编辑器。

您可以使用 PDF Arranger 通过可用菜单或使用拖放功能导入一个或多个 PDF 文件。然后，您可以将它们加入一个可以轻松保存到本地计算机的文件中。或者，可以将多页 PDF 文件分解为两个或多个文档。

重新排列和管理 PDF 中的页面
除了合并和拆分 PDF 文件之外，PDF Arranger 还可以帮助您旋转单个页面、裁剪页面以隐藏内容或从文档中永久删除页面。此外，PDF 文档的属性可以通过 PDF Arranger 轻松编辑。

还可以复制页面或将页面复制到剪贴板并将其粘贴到您喜欢的任何位置。此外，单击即可反转所有页面的顺序。
