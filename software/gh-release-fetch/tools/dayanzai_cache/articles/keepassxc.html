开源跨平台密码管理工具 KeePassXC 中文版由大眼仔旭发布。KeePassXC 是社区开发的 KeePass 开源分支，是 Windows 上最好的密码管理器之一。 KeePassXC 与 KeePass 不同，因为它可以在 Linux、Mac 和 Windows 上运行，但它也缺少一些原始软件的功能，例如插件支持。

在我们的 KeePassXC 评论中，大眼仔研究了为什么您可能会选择 KeePassXC 而不是已建立的商业密码管理器。

KeePassXC 功能特色

功能和实用程序

除了跨平台支持，KeePassXC 最有趣的功能是自动输入。 在 KeePassXC 中选择密码条目并点击自动填充快捷键会自动填写当前应用程序的用户名和密码字段。 这适用于大多数浏览器和桌面应用程序，无需单独的插件。

KeePassXC 没有内置的跨设备数据库文件同步功能，但由于文件是完全加密且独立的，您可以在 Google Drive 或 Dropbox 等平台上同步它们，而不必担心任何人在没有主密码的情况下访问数据。

安装设置

安装和设置 KeePassXC 相对简单。 您从 KeePassXC 网站下载应用程序并运行简单的安装程序。 KeePassXC 中的密码存储在安全的数据库文件中，系统会提示您创建新文件或从 KeePass1 或 1Password 文件导入密码。 您选择的主密码可以解锁您的数据库，如果您忘记了此密码，数据库将无法使用。

然后，您将填写所有密码的条目，可选择添加注释并使用密码生成器创建安全密码。

一个名为 KeePassXC-Browser 的独立浏览器插件可用于 Chrome 和 Firefox。 当您安装此浏览器插件并在计算机上打开 KeePassXC 数据库时，可以在检测到的网页上自动填写密码详细信息。 这仅适用于安装了 KeePassXC 的计算机，它不如基于云的密码管理器方便。

界面与性能

KeePassXC 的界面不是最现代的，但它是为功能而设计的。 密码条目可以分组，每个密码条目都有 URL、到期数据、注释和图标选项。 您可以添加属性和附件，并为浏览器集成和自动输入选择设置。 具有可自定义规则的密码生成器可以帮助您创建强密码。

安全

使用 KeePassXC 的主要原因之一是您永远不需要将密码存储在远程服务器上。 您的凭据本地存储在 AES-256 加密的数据库文件中，只能使用正确的密码进行解密。 即使黑客掌握了您的数据库文件，如果没有解密的能力，对他们来说也是无用的。 您可以通过双重身份验证进一步进行此操作，这意味着除非设备上存在密钥文件，否则无法打开数据库文件。

支持

KeePassXC是专为专业电脑用户设计的开源软件，相对基础的支持体现了这一点。 有 PDF 用户手册、常见问题解答和博客，仅此而已。 如果您有常见问题解答中未涵盖的问题，您可以通过 Internet 中继聊天 (IRC) 联系开发人员，并且该软件有一个 GitHub 问题跟踪器。 值得庆幸的是，Reddit 有一个非常活跃和友好的 /r/KeePass 社区，它讨论了所有 KeePass 变体，包括 KeePassXC。

计划和价格

KeePassXC 是根据 GNU 通用公共许可证的条款发布的，这意味着它可以免费供所有人使用。 开发团队接受 PayPal、Flatr、比特币和 Patreon 捐赠。 每月支付 5 美元或更多，您的姓名会与其他贡献者一起出现在软件的“关于”页面上。

对比

KeePassXC 的开发开始是因为 KeePass 仅适用于 Windows，但现在 KeePass 可以使用 Mono 安装在其他桌面平台上，对于需要跨平台密码管理器的人来说，KeePass 是一个合理的选择。

KeePass 提供比 KeePassXC 更多的选项和控制，尤其是在 Windows 上，所以如果您打算更频繁地使用 Windows，我们建议您检查一下。如果您主要在 Linux 上工作，我们仍然推荐使用原生 KeePassXC 客户端而不是 KeePass，因为它与操作系统的集成更加干净。

最后

KeePassXC 比 1Password 和 LastPass 等商业替代品更难使用，但它并不针对临时用户。使用 KeePassXC，您可以通过将所有内容存储在安全的本地文件而不是远程服务器上来完全控制您的密码，鉴于数据泄露的普遍性，这对于许多用户来说是更可取的。自动填充功能也是很少有替代品提供的有用功能。

大眼仔推荐 KeePassXC 作为高级用户的工具，他们希望处理自己的安全个人数据管理的各个方面，尤其是那些在 Linux 上工作的用户，但与基于云的密码管理器相比，大多数人会发现 KeePassXC 不方便。
