开源磁盘加密软件 VeraCrypt + x64 中文版由大眼仔旭（www.dayanzai.me）发布。VeraCrypt 中文版是一款适用于 Windows，Mac OSX 和 Linux 的免费开源磁盘加密软件。VeraCrypt 是 TrueCrypt 的分支，主要开发者是法国的 Mounir Idrassi，他在 TrueCrypt 基础上强化了防暴力免费功能。VeraCrypt 增强了用于系统和分区加密的算法的安全性，使其免受暴力免费攻击。VeraCrypt 还解决了TrueCrypt中发现的许多漏洞和安全问题。

开源磁盘加密工具 VeraCrypt 中文版

VeraCrypt 功能特色

VeraCrypt 可以用几种方式使用。你可以在文件中创建一个加密的虚拟磁盘，加密现有的物理卷，或者加密你的操作系统所在的系统分区。每种选项都有不同的应用场景，我们将在下面进行讨论。

第一个选项是使用 VeraCrypt 创建一个虚拟磁盘。这个虚拟磁盘作为一个加密文件存储。然后，你可以通过提供正确的认证（如密码或密钥文件）在操作系统中挂载该驱动器。数据在写入磁盘之前始终被加密，并在读取时解密。

你也可以以同样的方式加密计算机上的任何非系统磁盘卷。

系统加密
你可以使用 VeraCrypt 对系统分区或整个系统驱动器进行实时加密。从安全角度来看，这比仅仅加密特定卷有许多优点。

由于系统加密包括预启动认证，因此每次启动计算机时都需要输入正确的密码。如果有人没有密码偷走了你的电脑，即使他们取出硬盘并将其安装到另一台机器上，也无法访问你的驱动器中的任何内容。

隐藏卷
你还可以在 VeraCrypt 卷内创建隐藏卷。要访问你的隐藏卷，在挂载卷时需要输入另一个密码。带有隐藏卷的 VeraCrypt 卷与没有隐藏卷的 VeraCrypt 卷是无法区分的。

隐藏卷的概念是在受到胁迫的情况下仍能保持文件的秘密性。如果你被迫解密一个 VeraCrypt 卷，你可以输入次级密码，只显示无害的文件。而你的敏感文件仍然保密，强迫你的人则不会察觉。

界面和使用
使用 VeraCrypt 比使用微软的 BitLocker 略显复杂，主要是因为有更多的选择可供选择。但是设置 VeraCrypt 是通过其逐步向导完成的，这些向导提供了很好的指导。

界面包含一些其他有用的功能，比如加密基准测试工具、卷扩展器和密钥文件生成器。在首选项下，你会找到一长串调整选项来精确地按你的需求设置 VeraCrypt。

支持
VeraCrypt 提供了出色的文档，详细介绍了软件的所有功能，并且简洁易懂。

VeraCrypt 由法国公司 IDRIX 开发，尽管其代码大量基于已废弃的项目 TrueCrypt。对于技术支持，你首先可以联系 SourceForge 上的 VeraCrypt 论坛，那里有成千上万的主题讨论和票务系统。

VeraCrypt 的 Reddit 论坛也非常活跃，因此有多项基于社区的支持选项。

安全性
VeraCrypt 支持五种加密算法（AES XTS、Serpent、Twofish、Camellia 和 Kuznyechik），并且由于你可以组合它们，实际上有十五种加密算法的选择。还有四种哈希算法（SHA-512、Whirlpool、SHA-256 和 Streebog）。

VeraCrypt 已经修复了许多在 TrueCrypt 中发现的安全漏洞和问题，后者本身已经可以被认为是一个安全的系统。

由于没有服务器认证或直接共享能力，VeraCrypt 的安全性实际上相对简单，这意味着潜在的攻击途径较少。

VeraCrypt 的源代码在 2016 年由 Quarkslab 进行了独立审计，并且在随后的版本中解决了所有发现的漏洞。

竞争情况
全盘实时磁盘加密已经内置到了大多数版本的 Windows 中，形式为微软的 BitLocker。像 VeraCrypt 一样，你可以使用 BitLocker 来保护你的操作系统，这样没有人可以在不输入正确密码的情况下访问你的文件。

BitLocker 比 VeraCrypt 使用起来稍微容易些，因为它无缝集成在操作系统中。但 VeraCrypt 提供了许多 BitLocker 所不具备的功能，例如基于文件的虚拟加密磁盘以及多种强大的加密协议选择。VeraCrypt 也是跨平台的，并且源代码可用，因此你可以确信没有隐藏后门。

最终结论
VeraCrypt 是一个优秀的工具，用于保护你的敏感文件。缺少用于认证的中央服务器或内置云存储支持可能使 VeraCrypt 在涉及的计算机和用户数量增加时难以使用。但通过将这些功能排除在外，减少了潜在的攻击向量。

它的一些巧妙功能，如具有实时加密的基于文件的虚拟驱动器、具有单独密码的隐藏卷，以及具有启动时认证的系统加密，使其成为任何对加密文件感兴趣的人极为有用的免费工具。
