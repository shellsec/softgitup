不幸的是，Linux 用户不能使用它。 一个非官方的 Snap 软件包可以安装，但考虑到它依赖于 Wine 的嵌入式版本，它可能不令人满意。虽然我们确实有一些 Notepad++ 替代品的选项，但我遇到了一些尝试重新实现 Notepad++ 为 Linux 用户提供的功能的东西。 并且，具有类似的用户界面。此外，它还是一种跨平台产品。

Notepad Next 的目标是类似于 Notepad++ 提供的功能和用户界面。

请注意，您不应该期望提供相同级别的产品，因为 Notepad Next 仍在积极开发中（目前为 0.5 版本），需要进行一些改进。 话虽如此，记事本下一步是可用的和稳定的大部分。如果您需要它来执行非常重要的工作，开发人员建议您不要使用它。该应用程序使用 C++、Lua 和 Qt5 作为用户界面。

Notepad Next 是一个功能丰富的源代码编辑器，您也可以使用它来替换默认的文本编辑器。

其中一些主要功能包括：

  • 作为工作区的文件夹。
  • 支持一系列语言，如 C++，YAML，XML，LaTeX，PHP，Python，R，Rust 等。
  • 进行调整以禁用/启用UI的某些部分。
  • 支持录制宏、运行宏和保存录制的宏。
  • 文件中的查找和替换功能。
  • 行操作。
  • “编辑器”检查器，以获取有关文稿的详细信息。
  • 缩进参考线。
  • “撤消”/“重做”按钮
  • 放大/缩小
  • Lua 控制台
  • EOL 操作
  • 能够转换大写小写
  • 跨平台

另外值得注意的是，在撰写本文时，macOS 版本还处于高度实验阶段。 但是，它适用于 Windows、Linux 和 macOS。 因此，一旦开发人员解决了这些问题，它应该是一个完美的跨平台开源文本编辑器应用程序。
